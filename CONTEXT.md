# CoverPage Generator Context

This project is a cover page and laboratory report sheet generator designed specifically for students to easily format and generate report cover sheets.

## Language

**Onboarding Completion**:
The state where a student has filled out all required academic profile fields (student ID, university, department, section, subsection, level, term, and HSC batch), enabling access to the dashboard.
_Avoid_: Signup completion, registration completion

**Onboarding Guard**:
The client-side component that intercepts routing and redirects incomplete profiles to the onboarding page.
_Avoid_: Profile lock, registration guard
